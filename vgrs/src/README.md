## Pinout
Display:
| Pin  | Function   |
|------|------------|
| PA5  | SCREEN_CLK |
| PA6  | SCREEN_RES |
| PA7  | SCREEN_DIN |
| PA8  | SCREEN_DC  |
| PB10 | SCREEN_CS  |

PB3 -> Left button
PA0 -> Middle button
PB2 -> Right button
PA4 -> Coil Input
PB11 -> Coil Enable
PA1 -> Programmable LED
